仿真未重新执行 PRO/SPORT 全部控制器的完整运动验收，也没有重新认证台阶、真实装配或实机安全。验收要求见 [发布前测试需求](../AIQ/发布前测试需求.md)。

复现基础回归：加载 ROS 和消息环境，在启用双后端、EIR_GUI_TESTS=ON 及完整 PRO 模型测试路径的构建目录中执行：

```bash
ctest --test-dir build/aiq --output-on-failure \
  -R '^(flight_decoder_test|flight_recorder_test|runtime_test|runtime_simulation_test|ctrl_test|ctrl_hardware_test|ctrl_diagnostics_test|ctrl_startup_failure_test|ctrl_pro_simulation_test|remote_gui_test|ctrl_ros_perception_9500_onnx|ctrl_ros_perception_9500_libtorch)$'
```

完整 PRO 模型测试路径通过 CMake 参数 `-DEIR_CTRL_SIM_TEST_MODEL="$PWD/sdk/share/eir_mujoco/aiq11_pro/model/urdf/aiq11_pro.xml"` 设置。上述硬件接口测试为软件检查，不初始化机器人运动。
