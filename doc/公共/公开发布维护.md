# 公开发布维护

GitHub 发布使用三个仓库的 publish 分支。workspace、runtime 和 AIQ 应用均从独立根提交开始，不携带内部开发历史。内部开发继续使用原有分支，不将公开分支反向合并到内部开发分支。

公开 workspace 只登记 runtime、AIQ 应用两个 HTTPS 子模块；遥控 GUI 作为普通源码目录，保留独立 LICENSE 和来源。公开版本不登记内部实现、内部部署管理工具或 EQR 应用。

更新时先将审核后的 runtime / AIQ 修改同步到各自 publish，再更新 workspace 的固定子模块提交。策略、配置和 SDK 成套更新，不能直接合并整个内部开发分支。GitHub 已有 main 不会因创建 publish 被改写。

首次推送顺序为 runtime publish、AIQ 应用 publish、workspace publish。每次推送均包含对应 LFS 对象，不使用 --mirror、--all 或强制覆盖其他分支。确认 clone 文档、许可证和外部克隆验证后，再由仓库维护者决定默认分支。

`sdk/SHA256SUMS` 记录本次公开 SDK 文件校验值。策略与模型使用已有契约和来源记录；公开整理仅将训练元数据中的开发机绝对路径改为资源名称，不修改权重、控制参数或模型契约。

首次公开仍需补齐 prime_msgs 的确切 BSD 条款，并在 GitHub 上传全部 LFS 对象后进行外部全新克隆验收。当前本地构建通过不等于 GitHub 下载链路验收通过。
