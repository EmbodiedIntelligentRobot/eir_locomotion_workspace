# AIQ 相机接入

处理包位于 `sdk/ros2/eir_loco_depth_camera`，接口源码为 `src/depth_transport_msgs`。只发布图像或接收到 DepthStack，不代表视觉策略已启用。

完整命令、USB 选择与停止方式见 [相机 SDK README](../../sdk/ros2/eir_loco_depth_camera/README.md)。当前预编译包要求 Linux x86_64、CPython 3.10、ROS 2 Humble。

官方 Orbbec 驱动采集 → 图像处理 → 深度历史 → `/perception/depth_stack` → 控制应用。相机直连主控，默认 USB UID 为 `4-3`；可通过启动参数或 `EIR_DEPTH_CAMERA_USB_PORT` 覆盖，不固定单机序列号。官方驱动及其 SDK 需另外安装。

保留原图、策略图和诊断图话题。使用原始采集时间，不以接收时刻覆盖；处理后的数据不能再次归一化。深度尺寸、历史帧数、预处理版本与模型须成套配置；当前不同策略并非共用一个典型维度。

相机断流由控制器的深度有效性检查处理；采集监督重启相机不会自动解除运动故障或恢复控制。没有相机时仍可使用普通 AMP/MIMIC 仿真入口。

本次发布准备只执行软件和仿真验证，没有连接真实相机或机器人。真实 USB 断连、恢复、时间对齐和策略性能仍需在目标机验收。
