# 发布前测试需求

测试人员：刘鹏、才平、罗鸿博。

本次发布分支整理不重新认定全部控制器运动验收完成。软件与仿真结果见 [验证记录](../公共/验证记录.md)。

- 从 GitHub 全新克隆，确认两个子模块的固定提交与全部 LFS 对象可用；在没有内网 Git 权限的环境中编译。
- PRO / SPORT 分别验证 STILL、READY、AMP、MIMIC A–E 和已启用的特殊动作；包括入口限制、过渡、急停和故障锁定。
- PRO 分别验证拳头与三指夹爪策略、装配识别异常回退和手部控制。
- 感知策略验证合并/分离执行、所支持的 PT/ONNX 后端、平地与台阶、外力扰动，以及无效深度、断流和恢复边界。
- 真实相机确认 USB 绑定、采集参数、标定、处理契约和采集时间对齐；在目标主控测量推理耗时与视觉更新频率。
- 验证 GUI 模式/速度/退出与记录器写盘、存储异常、保存和解码。可选 CSV 转换需另装 motion_stream_tools，不作为基础遥控依赖。
- 实机运动需单独授权，在目标机使用正确标定、可靠支撑和可操作急停完成验收。
