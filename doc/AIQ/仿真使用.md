# AIQ 仿真

先按 [构建说明](../公共/构建与SDK.md) 编译，以下命令均从 workspace 根目录执行。

## PRO

```bash
source /opt/ros/humble/setup.bash
source build/interfaces/setup.bash
export AIQ11_PRO_MODEL="$PWD/sdk/share/eir_mujoco/aiq11_pro/model/urdf/aiq11_pro.xml"
./build/aiq/apps/eir_ctrl_demo_aiq11/eir_ctrl_demo_aiq11 apps/eir_ctrl_demo_aiq11/config/pro.yaml
```

该配置使用 ONNX，提供 AMP 与 MIMIC A–E。默认打开 MuJoCo 与遥控 GUI，初始为 STILL。先请求 READY，到位后再进入 RL。READY 成功发送且到位后自动释放悬吊。

## SPORT

```bash
./build/aiq/apps/eir_ctrl_demo_aiq11/eir_ctrl_demo_aiq11 apps/eir_ctrl_demo_aiq11/config/sport.yaml
```

SPORT 使用独立的机器人配置、关节映射、策略和控制频率。A–E 使用 `sport_mimic.yaml`，特殊动作使用 `sport_special_mimic.yaml`。不能混用 PRO 与 SPORT 模型。

## 感知与特殊动作

PRO 感知入口为 `config/pro_perception_9500.yaml`，默认 LibTorch；ONNX 单后端构建时，在本地配置副本中将 `inference.backend` 改为 `onnx`。该入口保留 AMP、MIMIC 与离线动作。

PRO 特殊动作为 `pro_special_mimic.yaml`。下蹲允许进入 AMP 或起立，起立仅从下蹲进入；仰卧/俯卧起身保持各自的入口限制。策略是否可切换由对应配置和就绪检查共同决定。

PRO A–E 有拳头（fist）与 LEGACY 三指夹爪（gripper）两组资源。仿真夹爪入口为 `pro_mimic_gripper.yaml`；硬件配置的双手反馈选择逻辑不代表仿真装配检测。

## 操作与退出

遥控 GUI 负责模式和速度；使用实体遥控器时保留其优先级。关闭 GUI 不会关闭控制器。完整退出在控制器终端按 Ctrl+C，等待线程和记录器收尾；关闭 MuJoCo 窗口可能触发反馈超时，不能作为恢复方式。

配置副本中可设 `runtime.headless: true` 和 `remote.gui: false` 进行无界面测试。配置中的相对资源路径以配置文件所在目录解析，移动副本时须一并修正路径。

位置越限只告警；非有限输入、关键反馈超时等仍锁定故障。故障后排障并重启，禁止通过放宽超时掩盖问题。

仿真模型包含楼梯，策略深度来自机身相机 site，与查看器视角无关。地形与本体感知组已随 SDK 资源提供；不要用未经对齐的旧 XML 替换。

本公开版本不依赖部署管理工具。源码目录启动流程如上；实机服务部署和运动验收不在本次发布分支整理的测试范围内。
